# Lead record template

Version 0.1 · Prepared 2026-10-13 · Proposed operating practice pending owner adoption

Private record: [[LEAD_ID]] · Owner [[RECORD_OWNER]] · Created [[RECORD_DATE]]

- Organization/contact/role/channel and source: [[LEAD_CONTACT]] / [[LEAD_SOURCE]]
- Permission/context for outreach and opt-out status: [[CONTACT_PERMISSION]]
- Problem, intended outcome, current workaround: [[CLIENT_NEED]]
- Service fit, budget range, timing, decision-maker: [[QUALIFICATION_NOTES]]
- Data/payment/regulatory warning flags: [[RISK_FLAGS]]
- Stage / entered / estimated value and evidence: [[SALES_STAGE]] / [[STAGE_DATE]] / [[OPPORTUNITY_VALUE_BASIS]]
- Last contact / promised follow-up / next action / owner / due: [[LAST_CONTACT_DATE]] / [[COMMITMENTS]] / [[NEXT_ACTION]] / [[NEXT_OWNER]] / [[NEXT_DUE]]
- Proposal/quote versions, private links: [[SALES_DOCUMENTS]]
- Won/lost date and reason: [[CLOSE_DATE]] / [[CLOSE_REASON]]

Do not treat an estimated deal value as booked revenue. Capture only information needed to qualify and serve the lead.
