# Project closeout

Version 0.1 · Prepared 2026-10-13 · Proposed operating practice pending owner adoption

Within the first agreed stabilization review after launch:

- [ ] Confirm accepted scope and list remaining support/defect commitments
- [ ] Reconcile actual hours, vendor charges, invoicing and approved changes
- [ ] Explain estimate-to-actual variance and improve future costing assumptions
- [ ] Confirm recurring entitlements, support queue, monitoring and backup ownership
- [ ] Complete source/config/docs, training, licenses and admin handover
- [ ] Remove temporary accounts and test data; rotate temporary secrets through secure systems
- [ ] Archive signed decisions, tests and release evidence privately
- [ ] Record client feedback and permission status for any testimonial/case study
- [ ] Assign renewal review and unresolved action owners/dates
